# PS4 Exploit Host Scaffold

هذا المجلد هو هيكل أولي مبني من الملف المرفق. تم حفظ المحتوى المرفق في `index.html`، لكن المرفق نفسه غير مكتمل وينتهي أثناء وسم HTML في السطر 598 تقريباً؛ لذلك لا يمكن اعتباره صفحة تشغيلية مكتملة.

الملفات الثنائية وملفات WebKit وKernel وملفات `common` و`payloads` أُنشئت كملفات فارغة مكانية فقط. لم يتم اختلاق أو تنزيل GoldHEN أو أي exploit/payload.

قبل الاستخدام، يجب استبدال الملفات المكانية بملفات أصلية وموثوقة تملك حق استخدامها، ومراجعة توافقها مع الجهاز والفيرموير. هذا الهيكل لا يشغّل أي exploit بصورته الحالية.

## GamerHack route integration

تم تحديث `index.html` ليكشف User-Agent ويختار مسار GamerHack المناسب، ثم ينتظر جاهزية AppCache قبل بدء العدّ التنازلي أو تحميل السلسلة. تمت إضافة شجرة `g2all/` المحلية من مستودع GamerHack العام، إضافةً إلى `style.css`، وأصبح `cache.manifest` يُنشأ من الملفات المحلية الموجودة داخل هذه الشجرة.

المسارات المستخدمة هي `g2all/700/alert.js` و`g2all/900/alert.js` و`g2all/css/main.js` و`g2all/slopkit/chain_lapse.js` و`g2all/slopkit/chain_poops.js`. صفحة التشغيل تمنع البدء قبل جاهزية الكاش، وتعيد محاولة تحميل السكربت حتى ثلاث مرات، وتُظهر الفشل بوضوح.

لا يوجد ضمان مطلق لمنع توقف الجهاز؛ الاستقرار يعتمد على إصدار النظام وملفات السلسلة الأصلية وحالة الجهاز. لم يتم تشغيل أي exploit أو ملف ثنائي أثناء تجهيز الحزمة.
